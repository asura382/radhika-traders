# Changelog

## 2.0.0 — Premium Showroom refinement

- Extracted the existing Radhika signboard emblem and introduced it as a local champagne-gold brand asset.
- Reworked the desktop/mobile navigation, collection mega-menu and quick product search.
- Refined homepage information hierarchy and editorial showroom sections.
- Added cropped detail studies from the existing local product photographs to make the sample catalogue more useful without presenting them as verified inventory.
- Expanded the illustrative catalogue to 11 references across six product groups.
- Improved collection type/finish filters, sorting, results count and empty states.
- Improved product detail specifications and related-product discovery.
- Fixed enquiry category/product prefill and improved the WhatsApp message preview.
- Added dynamic page titles, Open Graph metadata and stronger responsive styling.
- Preserved the presentation-demo boundary: no live database, admin panel, stock sync, checkout or production deployment.


## 2.0.2 - TypeScript build fixes
- Replaced the unsupported `lucide-react` Instagram brand icon import with a small inline SVG mark.
- Added `src/vite-env.d.ts` to provide Vite and CSS side-effect import declarations.
